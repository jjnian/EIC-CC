# EIC-CC 全新 UI 设计系统文档（评审稿 V1）

> 基于当前版本（feature/redesign-clean-ui）的信息架构，产出两套视觉方向。
> 交互、路由、后端契约完全不变；你选定方向（可混选）后再进入 Vue 开发。

---

## 0. 两案共用的骨架（不变项）

- 布局：左侧固定导航（232–236px）+ 顶栏（页面标题 / 全局搜索 ⌘K / 工作空间切换 / 用户）+ 内容区
- 导航分组：主导航（工作台、血缘图谱、经验库、AI 对话）/ 数据（数据源、血缘分析）/ 系统（设置）
- 8 个页面：/workspaces、/（工作台）、/graph、/experiences、/chat、/datasources、/analysis、/settings
- 图谱交互：分层布局（ODS→DWD→DWS→指标）、缩放/平移/拖拽、节点搜索高亮、上/下游追溯、边标签开关、保存布局
- 反馈：Toast（成功/失败）、SSE 步骤流（建图/调研/对话）、空状态引导文案
- 字体栈：`Inter, ui-sans-serif, system-ui, "PingFang SC", "Microsoft YaHei", sans-serif`

## 方案 A「墨 · 分析台」（Dark / 专业分析向）

### 配色

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 页面底 | `#0C0F14` | 全局背景 |
| 深底 | `#080A0E` | 侧边栏、画布底 |
| 面板 | `#12161E` | 卡片 / 抽屉 |
| 面板-浅 | `#161B25` | 输入框、工具按钮 |
| 边框 | `rgba(255,255,255,.06)` | 面板描边 |
| 主强调 | `#22D3EE`（Cyan） | 主按钮渐变、激活态、追溯高亮、辉光 |
| 辅强调 | `#3B82F6`（Blue） | 与 Cyan 组 135° 渐变 |
| 文字主 | `rgba(255,255,255,.88)` | 标题 / 正文 |
| 文字次 | `rgba(255,255,255,.5)` | 次级信息 |
| 文字弱 | `rgba(255,255,255,.3)` | 占位 / 时间戳 |
| 成功 | `#34D399` | 健康度、完成步骤 |
| 警告 | `#FBBF24` | 待审核、未入图 |
| 危险 | `#FB7185` | 血缘环、方向矛盾 |

### 图谱视觉编码

- 节点：面板色圆角矩形（r=10）+ 左侧 4px 类型色条；表 `#38BDF8` / 指标 `#A78BFA` / 维度 `#34D399`
- 边：默认 `rgba(148,163,184,.28)` 1.4px；推断边虚线 `5 4`
- 追溯高亮：`#22D3EE` 2.2px + `drop-shadow(0 0 6px rgba(34,211,238,.55))` 辉光
- 画布：22px 点阵背景（`rgba(255,255,255,.055)`）

### 组件

- 按钮主：Cyan→Blue 渐变，文字 `#080A0E`，hover 提亮 + 外发光
- 按钮次：`#161B25` 底 + `rgba(255,255,255,.09)` 边，hover 边变 Cyan
- 卡片：12px 圆角，面板底 + 6% 白边
- 输入：`#12161E` 底，聚焦边 `rgba(34,211,238,.4)`
- 导航激活：Cyan 文字 + `rgba(34,211,238,.1)` 底

### 气质关键词
深色沉浸、辉光图谱、高信息密度、键盘友好（⌘K）。参考：Linear / Raycast / Grafana。

### 阴影（层级靠阴影不靠边框）

- 卡片：`0 1px 2px rgba(28,25,23,.04), 0 4px 16px rgba(28,25,23,.05)`
- 浮层：`0 8px 32px rgba(28,25,23,.10)`
- 主按钮：`0 4px 14px rgba(124,58,237,.3)`

### 图谱视觉编码

- 画布：白色卡片容器 + 22px 点阵（`#D6D1C9`）
- 节点：白卡（r=12）+ 柔和投影 + 左侧 4px 色条；表 `#0EA5E9` / 指标 `#8B5CF6` / 维度 `#10B981`
- 边：默认 `#C9C4BC` 1.6px；推断虚线
- 追溯高亮：`#7C3AED` 2.6px + 紫色柔光

### 组件

- 圆角全面升级：卡片 16px、按钮/输入 10–12px、chip 全圆角
- 按钮主：Indigo→Violet 渐变 + 紫色投影，hover 提亮
- 按钮次：白底 + `#E7E5E0` inset ring，hover 边变 `#C4B5FD`、字变 Violet
- 输入：白底卡片阴影，聚焦 `ring-2 violet-200`
- 导航激活：`#F3F0FF` 底 + `#6D28D9` 600 字重

### 气质关键词
暖纸底、浮动卡片、大留白、演示友好。参考：Notion / Stripe / Linear 亮色。

## 间距与排版（两案一致）

- 间距刻度：4 / 8 / 12 / 16 / 20 / 24 / 32 / 48px；卡片内边距 16–24px；内容区 24px
- 字号：页面标题 15–17/600–700；卡片标题 13.5–14/600；正文 13–13.5；辅助 11.5–12.5；微标 10.5
- 图标：Lucide 14–16px，语义色配合

## 动效

- 通用过渡 150–180ms，`cubic-bezier(.2,.8,.2,1)`
- 卡片 hover 上浮 2–3px + 阴影加深；按钮 hover 提亮 8–10%
- SSE 步骤：绿点 + 竖连线逐条出现；发送/主操作带轻投影反馈

## 混选建议（开发时支持）

- 「B 的浅色骨架 + A 的暗色图谱画布」：长时间看图更舒适，需将画布令牌独立成 theme scope
- 两个方向均预留暗/亮切换可能性（Tailwind CSS 变量化），但 V1 只落地单主题
