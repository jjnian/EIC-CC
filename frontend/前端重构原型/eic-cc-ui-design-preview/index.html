设计评审稿 V1
方案 A Dark · Analyst Workbench

墨 · 分析台

深色沉浸式数据工作台。石墨底 + 青色辉光强调，图谱在暗色画布上呈现最佳可读性， 面向高频使用的专业分析师场景，气质接近 Linear / Raycast / 可观测性平台。

工作台 → 血缘图谱 → 经验库 → AI 对话 → 数据源 → 血缘分析 → 设置 → 工作空间 →
关键词：深色沉浸 · 辉光图谱 · 高密度信息 · 键盘友好
方案 B Light · Modern Workspace

澄 · 工作台

暖纸感明亮工作台。米白底 + 靛紫主色 + 大圆角浮动卡片，层级靠阴影与留白而非边框， 气质接近 Notion / Stripe，亲和、现代，适合全团队日常使用与演示汇报。

工作台 → 血缘图谱 → 经验库 → AI 对话 → 数据源 → 血缘分析 → 设置 → 工作空间 →
关键词：暖纸底 · 浮动卡片 · 大留白 · 演示友好

不变的骨架

两套方案共用同一信息架构：左侧导航 + 顶栏 + 8 个页面（工作台/图谱/经验库/对话/数据源/分析/设置/工作空间），交互逻辑与后端契约完全不变。

评审方式

点击上方卡片进入各页面设计稿（含模拟数据）。可两套混选——例如「B 的浅色骨架 + A 的暗色图谱画布」，开发时可组合。
